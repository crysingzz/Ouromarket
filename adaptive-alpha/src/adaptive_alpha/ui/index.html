Зарегистрировать сравнение

Условия фиксируются до наблюдений. Нужно минимум 20 сопоставимых торговых дней. Результаты лаборатории не заменяют этот период.

Артефакты Ouroboros

Спецификации и реализации сохраняются отдельно. Повторно используемый инструмент проходит три независимых matched-задания, операторское принятие и может быть отозван. Только отрецензированный harness запускается в отдельной очереди под gVisor; API и агенты не имеют доступа к runner socket.

Контроль результатов после допуска

Два последовательных подтверждённых периода убытка останавливают активную paper-стратегию. Правила фиксируются при допуске; исходная доходность — ориентир для сравнения, а не прогноз.
