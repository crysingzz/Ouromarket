## ADDED Requirements

### Requirement: Reference strategy generations
The initial orchestrator SHALL generate bounded template mutations with semantic descriptions and retained outcomes.

#### Scenario: Three-generation run
- **WHEN** a job permits three experiments
- **THEN** the registry contains three attempts with generation indices and child lineage

### Requirement: Distinct agent evolution benchmark
The target platform SHALL compare agent versions using identical datasets, tasks, models and budgets before promotion.

#### Scenario: Agent improvement proposed
- **WHEN** a workflow or prompt mutation is proposed
- **THEN** the change enters a separate benchmark and cannot change financial control policy
